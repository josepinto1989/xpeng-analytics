# XPENG Analytics 2.1.3

Released: 21 October 2026.

Version 2.1.3 adds a small but useful history reference to the application
navigation. It does not change calculations or the `.xpeng` history format.

## Visible data coverage

The earliest and latest available vehicle-telemetry dates now appear beneath
the XPENG Analytics logo in the desktop sidebar. This makes it possible to see
the overall period currently loaded without returning to Overview or Data.

The range is calculated across all available telemetry families rather than
from journey dates alone. It updates after additional files are imported and
uses compact formatting suited to the selected language. Mobile navigation
shows the same range below the section selector.
