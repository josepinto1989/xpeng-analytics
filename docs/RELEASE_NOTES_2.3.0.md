# XPENG Analytics 2.3.0

Version 2.3 makes long histories easier to review and adds a new way to see
and share the most interesting records in the available vehicle data.

## Lifetime Highlights

The new fullscreen **Highlights** area gathers top speed, peak drive power in
kW and hp, longest journey by distance and time, strongest acceleration,
braking and cornering, highest charging power, and recovered energy. A 0–100
km/h result is included only when the telemetry contains one uninterrupted,
complete acceleration from almost stationary to 100 km/h. The complete view
can be exported as a PNG generated locally in the browser.

## Clearer, manageable observations

Quality alerts now start collapsed. Odometer-based data-gap alerts show the
date, time interval, and affected distance. Individual alerts can be dismissed,
the area can be cleared, and everything can be restored later. Insights use the
same mark-as-seen and restore pattern. These choices are stored only as a local
browser preference and never delete or alter imported vehicle data.

## Better summaries and charging history

- Monthly summaries now include daily distance/consumption and AC/DC charging
  charts.
- Charging history can be filtered by All, AC, or DC and uses distinct colour
  labels for the charging type.
- Driving-context comparisons now show average consumption for each estimated
  context.
- Google Drive shows the backup's save date and time, and the first-use guide
  has been rebuilt around the current navigation and data-management flow.

All processing and image creation remain local. Calculated records depend on
the coverage and signals present in the XPENG export and are not official
vehicle specifications or performance claims.
